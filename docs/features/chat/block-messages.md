# 屏蔽消息

入口：Joker 设置 → 功能 → 聊天 → 屏蔽消息。

按「会话 / 关键词 / 发送人」三类规则，在微信处理新消息之前把命中规则的消息丢掉，命中时可以在通知栏一并静默。与「屏蔽消息遮盖」互补：这个负责真正拦掉，遮盖负责在聊天列表里盖住内容，两者互不影响，可以只开一个。

默认是**黑名单模式**：只屏蔽名单内的会话，再叠加关键词与发送人规则。

## 规则怎么定

点击「屏蔽消息」进入配置：

| 项 | 说明 |
| --- | --- |
| 白名单模式 | 开启后只有「会话名单」里的会话能提醒，其余一律屏蔽；关闭即黑名单模式 |
| 会话名单 | 选择要屏蔽（或白名单模式下要放行）的会话 |
| 按会话独立设置 | 为某个会话单独指定「只遮我点名的成员 / 全部遮盖 / 仅关键词 / 放行」，与其它会话互不影响 —— 多个会话各屏蔽各的人时用这个 |
| 屏蔽的消息不进通知栏 | 命中规则的会话或关键词会连通知一起静默 |
| 启用关键词遮盖 | 开：只有命中关键词的消息被处理；关：会话名单里的人所有消息一律处理（关键词输入框自动收起） |
| 关键词 | 每行一个，命中即处理 |
| 发送人 | 每行一个，wxid 片段即可 |
| 从群成员中选择 | 直接勾选群成员，不用手抄 wxid |

命中原因会记录（会话名单 / 白名单外 / 关键词 / 发送人 / 按会话规则），排查「为什么这条被拦了」时直接看原因。

## 搭配使用

- 想「拦掉但列表里看不到内容」：开「屏蔽消息遮盖」，聊天列表里命中的消息会被盖住，点一下该行才显示原文。
- 想「不拦消息、只是不打扰」：只用「屏蔽消息遮盖」，通知照常。

## 注意

- 屏蔽发生在微信处理消息之前，被拦下的消息不会再进入后续流程（包括通知、提示音、列表）。
- 规则只作用于本机：不会替对方撤回或删除任何内容，也不影响其他客户端。
- 关键词匹配不区分大小写；输入框里的内容每行一条，逗号不会当分隔符。
