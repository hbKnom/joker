# 聊天功能开关

入口：Joker 设置 → 功能 → 聊天 → 聊天功能开关。

在会话底栏菜单里加一个统一的「聊天功能」入口，把常用开关搬到聊天现场，不用来回跳设置页。本项没有单项开关，点进去即用。

## 底栏菜单里多出的三个动作

| 动作 | 作用 |
| --- | --- |
| 聊天功能 | 弹出聚合菜单：列出「聊天」分类下所有可以点开配置的功能（带名称与说明），点一条即打开它的配置页；菜单底部是「打开 Joker 设置」 |
| 屏蔽本会话 / 取消本会话屏蔽 | 一键把当前会话设为「全部遮盖」，再点一次取消。写入的是与设置页**同一份**按会话规则，两边状态永远一致 |
| 潜语：立刻重扫本会话 | 当场重新分析当前会话的可见消息，不用等分析节拍 |

## 注意

- 需要先进入一个会话；取不到当前会话时会提示「拿不到当前会话，请先进入会话」。
- 聚合菜单里只列出有独立配置页的聊天类功能（纯开关型功能不在此列），功能是否真的生效仍取决于它自己的开关与配置。
- 从会话里打开配置页依赖当前界面能拿到 Activity；拿不到时会提示「请回到 Joker 设置页打开 …」。
- 「屏蔽本会话」依赖「屏蔽消息」；「立刻重扫」依赖「潜语」。对应功能没开时，动作不会生效。
- 只想改设置、不想在聊天界面多一个入口时，可以关掉本项。
