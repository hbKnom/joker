# 潜语 · 聊天分析决策

入口：Joker 设置 → 功能 → 聊天 → 潜语 · 聊天分析决策。

在会话里给收到的消息生成一张分析卡（插在该条消息下方），一次分析、两处展示：气泡下的分析卡，以及（可选）回插进会话的说明。判定与表达是分开的 —— 决策结论由潜语自己算，大白话解读和「能直接发出去的那句话」交给通用对话模型写。

## 卡片里有什么

- **结论与强度**：情绪判定、置信度、建议强度（可以推进 / 稳妥回应 / 先观察 / 暂缓推进）。
- **言外之意**：把这条消息可能的意图写成一句解读。
- **风险提示**：例如「对方连续 N 条未见你回应」「你连续 N 条在自说自话」「本条情绪偏负」；置信度偏低时会明确标注「仅供参考」。
- **情绪趋势 / 互动均衡 / 话题标签 / 卡片扩展**：展示项，可在设置里逐项开关。互动均衡会画出双方发言占比，并指出谁在等回应。
- **回复**：由通用模型生成的一句可以直接复制发出去的话。「回复由 …生成」会标出模型来源。

长按卡片复制解读；有回复时长按复制回复，点击卡片展开/收起完整内容。分析失败或未配置时，卡片上会直接说明原因，点击可重试。

## 设置

| 分节 | 作用 |
| --- | --- |
| 总开关 | 功能总开关与卡片开关 |
| 卡片外观 | 解读、建议、话题、趋势等展示项，附卡片预览 |
| 卡片扩展 | 情绪趋势小结、互动均衡、话题标签等的细项 |
| 上下文与回插 | 喂给模型的上下文范围，以及是否把结论回插进会话 |
| 上限与性能 | 单条字数上限、分析队列上限、请求最小间隔（命中 429 会自动加倍） |
| 历史与统计 | 按人查看历史解读、复制某个人的解读、导出最近解读 |
| 运行状态与操作 | 本次运行的请求/成功/失败/缓存计数，重试失败记录、清空缓存、重新分析本屏 |
| 回复生成（通用模型） | 见下 |

## 回复生成（通用模型）

渠道不支持深度解读（第二轮请求直接报错）时，卡片就靠这一节兜住：潜语只负责决策判定，把「人话解读 + 可以直接发出去的那句话」交给一个通用的对话模型。

- **模型来源**：直接选「聊天分析 → AI 模型」里已经配好的条目（OpenAI 兼容），默认跟随聊天分析当前模型，改完立即生效；也可以在设置里现场「＋ 新建模型提供商」，填名称 / Base URL / API Key / 模型（支持「拉取模型」列出候选）。
- **测试生成**：立即发一次请求并显示结果，用来把「模型选错 / Base URL 或 Key 错 / 提示词有问题 / 超时」区分开。
- **不会拖住分析队列**：补写走短超时请求，并带总预算闸；一次分析已经跑太久就直接放弃补写，只保留决策结论。

回复的写作要求沿用聊天自动回复那套去 AI 味规则：长度匹配、不写助手腔、不列点、不提 AI。

## 注意

- 必须自己配置模型渠道（Base URL / API Key）。没配时卡片显示「未配置」，不会发任何请求。
- 文本只发给你自己配置的那个模型服务，不经过任何中转。
- 超过单条字数上限的长消息会被跳过并在卡片上标注（上限可在设置里调）。
- 分析队列有容量上限，超出会排队等空位，不会丢消息；为摊平突发，相邻请求之间有最小间隔。
- 结论是模型判断，不是事实认定：置信度低时请当参考，不要据此做不可逆的决定。
