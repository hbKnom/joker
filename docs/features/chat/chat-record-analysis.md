# 聊天记录分析

入口：Joker 设置 → 功能 → 聊天 → 聊天记录分析（开关）；使用时**长按任意消息 → 菜单里的「分析」**。

对选定时段内的纯文本聊天记录做两件事：本地统计报告，以及（可选）AI 总结。统计完全在本地算，不上传任何内容；只有点「AI 总结」时才会把抽样后的文本发给你自己配置的模型。

## 统计时段

打开分析后先选时段，预设为：今天 / 昨天 / 本周 / 上周 / 本月 / 上月（各自的起止范围在选中时会写明）。本地统计与 AI 总结都只读取所选时段内的纯文本消息；该时段内没有纯文本消息时会直接说明，不会让 AI 空转。

## 报告内容

| 部分 | 内容 | 是否联网 |
| --- | --- | --- |
| 本地统计报告 | 消息量等本地统计 | 否 |
| 发言排行 | 按人统计发言条数占比 | 否 |
| AI 智能洞察 | 基于抽样转录的模型总结，可复制 | 是，发给你配置的模型 |

维度包按需开关，每个包 4 项分析，都在同一次扫描里顺带算完，关掉只是不输出那一块：

- **时间维度包**：活跃日历与趋势、回应速度、活跃密度与连续、连击与轮次。
- **关系维度包**：接话·提问·默契、复读与重复、回复速度榜、个人作息雷达。
- **语言维度包**：打字习惯、约定与提醒、时段话量画像、用词广度。

## 设置

入口：分析弹窗里的「设置」。

- **功能开关**：AI 总结 / 本地统计 / 发言排行，各自独立开关。
- **分析参数**：
  - 分析条数上限：参与分析的消息总数上限，`0` 表示全部（越大越慢，大群建议 5000~20000）。
  - 抽样上限：喂给 AI 的最大文本条数（超出部分等距抽样），建议 200~2000。
  - 单条文本上限：一条消息喂给 AI 的最多字数，超出的消息不参与。
  - 喂给 AI 的文本上限：整段记录的总字数上限；模型上下文窗口小就要调小，否则服务端会报上下文超限。
- **AI 模型**：管理 OpenAI 兼容模型，支持配置多个并按需选择。每个条目填名称 / Base URL / API Key / 模型 ID / 请求路径，可「测试连接」。这套配置同时被「潜语」的回复生成复用，改一处两处都生效。

## 注意

- 只处理纯文本消息；图片、语音、文件、表情不参与统计与总结。
- 已有分析任务在跑时会提示「已有分析任务进行中」，避免并发重复扫描。
- AI 输出是模型总结，不是统计事实；与本地统计对不上时以统计为准。
