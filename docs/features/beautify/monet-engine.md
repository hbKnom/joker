# 微信界面主题取色

入口：Joker 设置 → 设置 → 界面。

使用动态壁纸取色或手工种子颜色，选择调色板样式与颜色规格，再开启「同时对微信生效」，重启微信后让支持的微信绿色组件使用该配色。

动态壁纸取色需要 Android 12 或更高版本；手工种子颜色不等同于系统壁纸取色。此能力由主题设置控制，无独立的「莫奈引擎」功能开关。

需要生成资源覆盖 ZIP 时，使用[莫奈引擎模块生成器](monet-engine-module-generator.md)。启用生成器模式后，资源覆盖由安装的模块负责，普通取色 hook 会让出处理。

## 红包与转账卡片

取色对微信生效后，聊天列表里的红包与转账卡片（收 / 支两个方向）也会跟随主题重绘，**自己已经领取过的那张同样会重绘** —— 已领取的卡片在宿主里不再带「待领取」类状态词，模块据此判定为已结算后再上色，所以它不会因为「已经点开过」而退回原版。

这一部分不需要单独开关：取色没生效时它一个像素都不碰；被宿主重新设置背景后会自行补回。
