# 侧滑面板日历

入口：Joker 设置 → 功能 → 界面美化 → 主页侧滑面板（把「日历」放进侧栏）；日历自己的开关在面板里的「日历设置」。

侧滑面板里内嵌一个日历，带公历 / 农历 / 干支 / 节日 / 节气 / 休班角标与黄历宜忌。配色跟随模块主题（莫奈取色）。

## 视图

月 / 周 / 日三种视图，加一个「今天」快捷跳转。三视图共用同一份黄历数据源，所以宜忌在哪个视图里都显示，切换视图不会丢内容。

## 显示项（日历设置）

| 项 | 说明 |
| --- | --- |
| 显示节日名 | 节日与节气名称 |
| 显示休/班角标 | 法定放假与调休上班的角标 |
| 显示宜忌 | 当日宜、忌 |
| 显示节日倒计时 | 距离下一个节日还有多久 |

黄历信息包括一行干支与生肖（形如「甲辰年 · 属龙 · 八月 · 廿三」）、建除（形如「建日」），以及「宜：… 忌：…」。

## 数据覆盖范围（重要）

| 数据 | 范围 |
| --- | --- |
| 宜忌 | 1901-01-01 ~ 2101-01-01（本地黄历数据文件） |
| 节日 / 节气 | 2026、2027 两年有静态表；静态表未覆盖的年份按内置算法推算 |
| 法定放假 / 调休 | 2011 ~ 2026 有快照；2027 的条目没有法定区间信息，因此**2027 年不会有「休」角标** |

两点已知现象，不是开关坏了：

- 同一天同时是节日与节气时（例如既是节气又是父亲节），按数据表规则**后写的覆盖先写的**，只显示一个名字。
- 静态表未覆盖的时段（例如 2026 年初、2027 年 10 月之后）依靠算法推算，节日与休班可能有偏差。

## 注意

- 日历属于「主页侧滑面板」的一部分：面板没开、或侧栏里没放日历卡时，日历设置不会显示出来。
- 只读不写：日历不会创建日程、不做提醒，也不修改任何系统日历数据。
