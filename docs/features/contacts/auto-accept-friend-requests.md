# 自动通过好友申请

入口：Joker 设置 → 功能 → 联系人与群组 → 自动通过好友申请。

收到好友申请时调用协议层直接通过，并可选地在通过后自动打标签、发一句招呼。默认只记录不动作 —— 「真正自动通过」关着的时候，这个功能不会替你做任何联系人操作。

## 设置

| 项 | 说明 |
| --- | --- |
| 真正自动通过 | 关闭 = 只记录日志；开启后收到申请立即调用协议层通过 |
| 通过延迟（毫秒） | `0` = 立即；填数字可错开时间 |
| 通过后自动打标签 | 通过成功后打上标签，标签名可填 |
| 通过后自动打招呼 | 通过成功后发一条消息；文案支持 `$nickname` / `$talker` / `$date` / `$time` 占位符，可设打招呼延迟 |
| 无 ticket 时跳过 | 默认关：申请报文里没有 ticket 也照样尝试通过（wxid 已唯一确定申请人，失败只会被服务端拒绝，不会误通过他人）；打开后严格按旧行为，缺 ticket 只记录 |
| 运行状态 | 「解析 N · 通过 N · 失败 N」+ 最近事件列表与消息表插入类型，点一下清空计数 |

## 怎么确认它在工作

把「真正自动通过」关着，让对方发一次好友申请：运行状态里应出现解析事件与命中原因。确认能稳定命中后再打开开关，避免在没搞清命中条件前就真的动联系人。

## 注意

- 通过动作走的是微信自己的协议层接口，不做任何伪造；服务端拒绝时只会失败，不会被本机强行写入。
- 自动打招呼是在通过成功后额外发消息，与「聊天自动回复」是两套独立逻辑。
- 打标签需要标签名非空；标签相关操作失败不影响「已通过」这个结果。
- CI 只能证明代码编进了包，实际命中情况请对着运行状态看。
